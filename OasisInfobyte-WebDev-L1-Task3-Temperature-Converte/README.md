# 🌡️ Temperature Converter Website

A simple and interactive Temperature Converter Website developed as **Task 3** of the **Oasis Infobyte Web Development & Designing Internship**.

The website allows users to enter a temperature and convert it between **Celsius, Fahrenheit, and Kelvin**.

## 🚀 Features

- 🌡️ Convert temperature between Celsius, Fahrenheit, and Kelvin
- 🔢 Validate numeric input
- ⚠️ Show error messages for invalid input
- ❄️ Prevent temperatures below absolute zero
- 🔄 Convert temperature using a simple Convert button
- 📊 Display Celsius, Fahrenheit, and Kelvin results
- 📱 Responsive design for different screen sizes
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## 📐 Conversion Formulas

### Celsius to Fahrenheit

`°F = (°C × 9/5) + 32`

### Celsius to Kelvin

`K = °C + 273.15`

### Fahrenheit to Celsius

`°C = (°F - 32) × 5/9`

### Kelvin to Celsius

`°C = K - 273.15`

## ▶️ How to Use

1. Enter a temperature value.
2. Select the input unit.
3. Click the **Convert** button.
4. The converted Celsius, Fahrenheit, and Kelvin values will be displayed.
5. If an invalid temperature is entered, an error message will be shown.
